# 🚀 Проект автоматизированного тестирования на Python (AQA)

Учебный проект для изучения базовых инструментов автоматизации тестирования: **Python**, **pytest**, **Git** и виртуальных окружений.

---

## 🛠 Как запустить проект локально (с нуля)

Выполните следующие шаги в терминале вашей среды разработки (например, PyCharm или VS Code):

### 1. Создайте виртуальное окружение
Изолированная среда нужна, чтобы зависимости проекта не конфликтовали с другими программами на компьютере:
```bash
python -m venv .venv
2. Активируйте виртуальное окружение
Команда включает изолированную среду (в терминале должен появиться префикс (.venv)):

В Windows (PowerShell):

Bash
.venv\Scripts\Activate.ps1
В macOS / Linux:

Bash
source .venv/bin/activate
3. Установите необходимые зависимости
Скачайте все библиотеки, зафиксированные в файле requirements.txt:

Bash
pip install -r requirements.txt
